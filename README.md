## Pure3D Level Loader Unity
Explore p3d levels in Unity

![alt text](https://keehanroberts.com/images/github/P3D-Level-Loader-Unity.jpg "Pure3D Level Loader Unity")

### Requirements
NetP3DLib

### Instructions
Place models and textures from The Simpsons: Hit & Run in to Resources/Level # folder  
Alternatively, models from Composite Drawable Chunks can be placed in to Resources/Level #/Model name folder

### Controls
W, A, S, D to move  
Right Mouse Button to look  
Left Mouse Button to set spawn  
Left Shift to increase movement speed  
E, Q to move on up axis  
V to switch mode  
Tab to show/hide UI
